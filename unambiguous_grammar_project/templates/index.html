Ambiguous Grammar (G₁)
Multiple Trees

Allows more than one distinct leftmost derivation (and parse tree) for at least one string in its language.

E → E + E | E * E | ( E ) | id
Precedence Hazard: For id + id * id, G₁ permits both (id + id) * id (addition first) and id + (id * id) (multiplication first).
Unambiguous Grammar (G₂)
Deterministic

Enforces strict mathematical operator precedence (* over +) and left-associativity.

E → E + T | T
T → T * F | F
F → ( E ) | id
Unique Parse Tree: For id + id * id, G₂ strictly produces id + (id * id), matching standard mathematics.

Formal Languages & Automata Theory Fundamentals

Essential theoretical concepts explaining grammar construction, derivations, and parsing mechanics.

1. Context-Free Grammar (CFG)

A Context-Free Grammar is formally defined as a 4-tuple:

G = (V, Σ, R, S)
  • V (Non-terminals): Syntactic variables like {E, T, F}.
  • Σ (Terminals): Alphabet symbols like {+, *, (, ), id}.
  • R (Productions): Rules of the form A → α where A ∈ V, α ∈ (V ∪ Σ)*.
  • S (Start symbol): Distinct initial variable S ∈ V.

2. Grammatical Ambiguity

A CFG is called ambiguous if there exists at least one string w ∈ L(G) that has:

  • Two or more distinct parse trees, OR
  • Two or more distinct leftmost derivations.

Conversely, an unambiguous grammar guarantees that every valid string in the language maps to exactly ONE unique parse tree.

3. Derivations: LMD vs RMD

A derivation is a sequence of production steps replacing non-terminals with right-hand sides:

  • Leftmost Derivation (LMD): In every step, the leftmost non-terminal symbol in the sentential form is replaced.
  • Rightmost Derivation (RMD): In every step, the rightmost non-terminal symbol is replaced (also called canonical derivation in bottom-up parsing).

4. Operator Precedence & Associativity

Disambiguation requires embedding two key algebraic rules into the productions:

  • Precedence via Stratification: Operations evaluated first (multiplication) appear lower in the derivation tree (under T) than operations evaluated later (addition under E).
  • Associativity via Recursion: Left recursion (e.g. E → E + T) forces left-to-right grouping: (a + b) + c.
